# Genre-aware Metal Album Cover Generation (Diffusion + LoRA)

## Overview
This project explores a genre-aware system for generating metal album covers.  
We adapt a pretrained text-to-image diffusion model to metal aesthetics and evaluate outputs with multimodal metrics.

## Goals

* Build a “master” dataset linking **album cover + band + album + target genre (subgenre) + lyrics**.
* Generate album covers with a pretrained text-to-image diffusion model under multiple prompt modes:

  * **G**: genre + band + album (metadata-only)
  * **L**: lyrics-summary-only
  * **GL**: combined metadata + lyrics summary
  * **C**: prompt augmented with an automatic **caption** generated by *Florence-2-base*
  * **GC**: metadata + caption
  * **GLC**: metadata + lyrics summary + caption
  * **P**: additional experimental prompt variants
* **LoRA training:** Fine-tune a lightweight LoRA adapter on real metal cover art (Stable Diffusion v1.5) using simple genre-conditioned captions.

* Compare **baseline vs LoRA-adapted** generation and evaluate outputs using lightweight multimodal metrics (e.g., **CLIP similarity**, **zero-shot genre probe**, **kNN distance in CLIP space**).

* **NST experiment:** As a quick post-processing test, apply neural style transfer to baseline Stable Diffusion outputs using **random real covers from the same genre** as style references; results were visually very similar, so NST was not analyzed further.


## Datasets (Kaggle)
- [Large Metal Lyrics Archive (228K songs)](https://www.kaggle.com/datasets/markkorvin/large-metal-lyrics-archive-228k-songs)
- [Metal Albums Artwork](https://www.kaggle.com/datasets/benjamnmachn/metal-albums-artwork)

## Method

### 1) Data collection, unification, and download

* Merge CSVs by band/album names
* Remove duplicates/conflicts
* Map subgenres to broader style clusters (here, death/thrash metal)
* Keep only albums with reliable cover + genre + lyrics

### 2) Exploratory Data Analysis (EDA)

* Validate merged dataset consistency and class balance (death vs thrash).
* Analyze lyrics length and basic cover statistics.
* Extract handcrafted visual features and test simple classifiers.
* Encode covers with **CLIP embeddings** for visualization, clustering, and zero-shot genre probing.

### 3) Text cleaning and TF–IDF preprocessing

* Clean and normalize lyrics (remove annotations, URLs, non-alphabetic noise, repetitions, and domain-specific stopwords), keeping only English texts.
* Produce a structured, denoised corpus suitable for **TF–IDF keyword extraction** and prompt construction (L / GL modes).

### 4) Captioning (cover-image descriptions)

* Generate descriptive captions for album covers using **Florence-2-base**.
* Cache captions and apply an anti-cheat strategy (crop + re-caption) to reduce cases where the model reads band logo and album name.

### 5) Prompt Builder (G / L / GL / C / GC / GLC / P)

Multiple prompt construction strategies were explored:

* **G (Genre)** – Template-based prompt including subgenre, band name, and album title.
* **L (Lyrics)** – Prompt built from a short summary of lyrics using keyword extraction and templated phrasing.
* **GL (Genre + Lyrics)** – Combination of structured metadata and lyrical summary.
* **C (Caption)** – Prompt generated automatically using *Florence-2-base*, which produces a descriptive caption of the album context.
* **GC (Genre + Caption)** – Metadata prompt combined with the Florence-generated caption.
* **GLC (Genre + Lyrics + Caption)** – Full combination of metadata, lyrical summary and generated caption.
* **P (...)** – Additional experimental prompt variations designed to explore alternative conditioning strategies.

### 6) Diffusion model loading and baseline testing

* Load a pretrained text-to-image diffusion model (Stable Diffusion v1.5) and validate generation settings.
* Generate baseline samples to confirm the pipeline works before adaptation.

### 7) LoRA training and initial testing

* **Domain adaptation (LoRA):** Fine-tune a LoRA adapter on real metal cover art to inject metal-specific aesthetics.
* Run quick tests to verify the adapter loads correctly and changes generations.

### 8) Base SD vs LoRA generation

* Generate paired outputs from **baseline SD** and **LoRA-adapted SD** across prompt modes (**G / L / GL / C / GC / GLC / P**), using matched seeds for fair comparison.

### 9) Base SD vs LoRA evaluation

Evaluation is done on the models from the previous step - a baseline diffusion model vs an adapted one (using LoRA).

* **Text–image alignment:** CLIP cosine similarity between the prompt and the generated image (reported per mode and per genre).
* **Genre signal probe** CLIP zero-shot genre matching using genre text prompts (death vs thrash).
* **Embedding-space realism:** kNN minimum cosine distance in CLIP space from generated covers to the closest real cover (reported per prompt mode and per model variant - baseline or LoRA).
* **Style coverage** Compare real vs generated distributions.

### 10) Neural Style Transfer (NST) experiment

* **Neural Style Transfer (NST):** Implemented as a small exploratory baseline by applying style transfer to **baseline Stable Diffusion outputs** (content) using **random real covers from the same genre** as style images. In practice, the stylized results were visually very similar to the original generations, so NST was not pursued further as a competitive baseline.
